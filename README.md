# Talk Instead of Type

A friendly, self-contained guide to private, offline voice dictation on Mac
and Windows: hold a key, speak, release, and the text appears where your
cursor is. Everything runs locally; no audio ever leaves the machine.

**Read the guide:** https://maheshmirchandani.github.io/talk-instead-of-type/

Contents:

- `index.html`: the main guide. Covers [VoiceInk](https://github.com/Beingpax/VoiceInk)
  on Apple Silicon Macs and [Handy](https://github.com/cjpais/Handy) on
  Windows and Intel Macs, from install to uninstall.
- `VoiceInk-Build-and-Setup-Guide.html`: a companion for the technically
  inclined, building VoiceInk from source on macOS, with every command and
  every error met along the way.

Both documents are single HTML files with no external assets; they work
offline and print cleanly.
