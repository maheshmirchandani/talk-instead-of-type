Talk Instead of Type on Windows

Private voice dictation on Windows · Version 1 · Last updated: Tue, 29 Sep 2026 20:41
Versions covered: Handy 0.9.7 and Ollama 0.34.4 · Companion to the main guide

1. Start here

This guide sets up voice dictation on a Windows PC that runs entirely on your own computer. You hold a key, speak, let go, and your words appear as text wherever your cursor is: an email, a chat box, a document, a search bar. Nothing you say is sent anywhere.

It is the Windows companion to the main guide, which has a short section on Handy for Windows. This guide goes further: it compares the private options available on Windows, walks through the recommended one in full, and adds optional AI clean-up of your text, still without anything leaving your PC.

Who this is for: anyone comfortable installing an app and changing a setting. No technical background needed. The guide assumes you will dictate in English; other languages are noted where they differ.

A note on testing

I use a Mac, so I have not been able to try the Windows steps myself. Everything here is drawn from each app's official documentation and release notes, checked in September 2026. If you follow this guide on Windows, I would be very glad to hear how it went, whether it worked first time or you hit a snag along the way. Your feedback will help make it better for the next reader. You can share it on the guide's GitHub page (a free account is needed), or as a comment on the LinkedIn post where I shared it.

Why Handy

Handy is free and open source, its installers are digitally signed, it needs no account, and it is actively maintained, with a new release every few weeks. It is also the app the main guide suggests for Macs, so Mac and Windows users in the same household or team can help each other. Its AI clean-up is still marked experimental; dictation itself is the mature part. Murmure is a close second if AI clean-up matters most to you.

3. Not covered, and why

  • Windows voice typing (Win+H). It uses Microsoft's online speech recognition, so your voice goes to Microsoft's cloud, and it works only with "Online speech recognition" switched on.
  • Wispr Flow and Aqua Voice. Polished, but transcription happens in their cloud. Wispr Flow is free for 2,000 words a week, then US$12 a month billed yearly; Aqua Voice gives 1,000 free words, then US$8 a month billed yearly.
  • Superwhisper for Windows. Closed source. Its local transcription is free, but its only on-device AI clean-up model is in the paid plan, marked experimental, and not available on ARM PCs.
  • Dragon Professional. Installed software, but aimed at businesses and sold through a sales enquiry rather than a published price. The home editions stopped being sold in 2023.
  • WhisperWriter and Whispering. Open source, but no longer being released for Windows: no new version since January 2024 and December 2025 respectively. WhisperWriter also needs Python to set up.

Windows 4. Install Handy

Requirements: Windows 10 or 11, on an ordinary Intel or AMD PC (x64) or an ARM laptop. Handy does not publish a minimum Windows version or memory requirement; allow roughly 1 GB of free disk space for the app and one speech model. Version covered: 0.9.7.

  1. Check your system type: Settings → System → About, and look at System type. "x64-based processor" covers almost everyone. "ARM-based processor" means you need the ARM64 download.
  2. Go to handy.computer/download and download the Windows setup (.exe) file for your system type. The .exe installs Handy just for you. The .msi installs it for every user on the PC, which mainly suits IT departments. Comfortable with the command line? winget install cjpais.Handy also works, although that package is maintained by the community rather than by Handy's developers.
  3. Run the installer. If a blue "Windows protected your PC" box appears, click More info and check that the publisher reads YNYNG LLC before choosing Run anyway. Handy's releases are signed under that company name rather than "Handy". The signature shows the file has not been altered since it was published. If the publisher is different or "Unknown", stop and download the file again from handy.computer.
  4. If Microsoft Defender reports a threat in the installer, do not override it. This happened once, to version 0.9.5, and the developer reported it to Microsoft as a false alarm. Even so, the safe response is to delete the file and try again later with the newest version, rather than telling Defender to allow it.
  5. Finish the installation and open Handy. It lives in the system tray: the small icons near the clock, possibly behind the ^ arrow.

Windows 5. Microphone and speech model

  1. Let desktop apps use your microphone: Start → Settings → Privacy & security → Microphone. Switch on Microphone access, Let apps access your microphone and Let desktop apps access your microphone. If any of these is off, Handy hears nothing and fails silently. It is the most common Windows snag.
  2. When Handy says "To get started, choose a transcription model", pick Parakeet Unified EN (marked Recommended, about 730 MB) and let it download. It is English only and runs well on an ordinary processor. Nothing is chosen for you, so this step matters. Dictating in other languages? Choose Nemotron Streaming 3.5 (28 languages) instead, or use the Show all models link to find Parakeet V3 (25 European languages).
  3. Open Handy's settings from its tray icon and choose your microphone. Handy picks its own microphone, separately from the Windows default. Some built-in laptop microphones record only silence in Handy; if that happens, a headset or USB microphone is the reliable fix (see section 7).

Windows 6. The shortcut and your first test

  1. The default shortcut is Ctrl+Space. Hold it, speak, and let go. In the default "Auto" mode you can also tap it once to start and again to stop. Holding is the better habit, because the microphone is live only while your finger is down. You can change the key, or fix the mode to Hold or Toggle, in Handy's settings.
  2. Test it: open Notepad, hold the shortcut and say "Thanks for sending this over. Can we talk on Thursday afternoon?", then let go. A moment later the sentence should appear, capitals and question mark included. If nothing appears, see section 9.
  3. To have Handy ready every time you sign in, switch on Launch on Startup in its Advanced settings. It is off by default. Start Hidden, next to it, keeps the window out of your way.
  4. Optional: add names and specialist terms under Custom Words. This helps the model spell names it would otherwise guess at, and works best on plain words made of letters and numbers. Handy also removes filler words such as "um" by default.

Windows 7. Known snags, and what to do

These come from problems other Windows users have reported on Handy's GitHub page. Most people meet none of them.

What happensWhat to do
Handy pastes something you copied earlier instead of your wordsPress Ctrl+Shift+D to open Handy's Debug menu and switch on Reliable Paste (Beta), or increase Paste Delay.
Nothing appears in an app running as administrator, or Handy freezes thereA known limitation. Dictate into a normal window, then copy the text across.
A laptop's built-in microphone records only silenceUse a headset or USB microphone and select it in Handy's settings.
Handy crashes or freezes while transcribing, or the screen turns blueThe graphics card is the likely cause. In Handy's settings, change graphics acceleration from Auto to the processor (CPU) option (check in the app for its exact name), and keep your graphics driver up to date.

8. Optional: AI clean-up with Ollama

Experimental

Handy marks this feature as experimental and switches it off by default. It also works on a different shortcut from normal dictation, so read step 7 before you try it.

Handy can pass what you said through a small AI model on your own PC, which fixes punctuation, removes filler words and turns numbers into digits, without rewording you. Spoken: "So um I think we should uh move the meeting to Thursday". Typed: "I think we should move the meeting to Thursday." It stays private by using Ollama, a free app that runs AI models on your PC and, by default, accepts requests only from your own computer.

Is your PC up to it?

Ollama needs Windows 10 (22H2) or newer and at least 4 GB of disk space for itself, plus the model. It uses a recent NVIDIA or AMD graphics card if you have one, and otherwise runs on the processor, more slowly. Start with the smaller model below, and move up only if clean-up is quick and you want better results.

  1. Download Ollama from ollama.com/download/windows and run OllamaSetup.exe. It installs in your own user folder, needs no administrator rights, and starts with Windows as a tray app. To stop it starting automatically: Task Manager → Startup apps → ollama → Disable.
  2. Open Command Prompt (Start, type cmd, press Enter) and run ollama pull gemma3:4b. A 3.3 GB download that suits most laptops. With a good graphics card, try gemma3:12b (8.1 GB) instead. The smallest sensible option is llama3.2:3b (2.0 GB), although on a Mac, models this small missed some filler words in testing. Avoid models that "think" out loud, such as Gemma 4 and Qwen 3, which may add their reasoning to your text.
  3. In Handy, open Advanced settings and switch on Experimental Features.
  4. In the new Experimental group, switch on Post Processing. A Post Process page appears.
  5. On that page, choose the Custom provider. Leave the address as http://localhost:11434/v1 and the API key empty, and type gemma3:4b (or the model you downloaded) as the model. The address is Ollama's, on your own PC. The model name must match exactly what you downloaded; ollama list in Command Prompt shows it.
  6. Select the built-in prompt Improve Transcriptions. It fixes spelling and punctuation, turns number words into digits and removes filler words, and it is told not to reword or reorder what you said.
  7. To dictate with clean-up, use Ctrl+Shift+Space in place of Ctrl+Space. This is the part that surprises people: the normal shortcut never uses clean-up. Use the plain shortcut for quick messages and the clean-up shortcut for longer, rambling ones. If the AI step fails, Handy types your original words instead, so nothing is lost.
  8. Test it with the messy sentence above. The first run after Ollama starts is slower while the model loads. If filler words survive, try the larger model.

10. Updating

  • Handy offers new versions itself; accept them. You can also install a newer version over the old one from handy.computer/download. Settings and models are kept.
  • Ollama: download the latest installer from ollama.com/download/windows and run it. Downloaded models are stored separately and are not affected.
  • After any update, do one quick test dictation. If text stops appearing, start with the microphone checks in section 5.

11. Uninstalling

Handy

  1. Quit Handy from its tray icon.
  2. Settings → Apps → Installed apps → Handy → Uninstall.
  3. Delete the leftover data: press Win+R, type %APPDATA%, press Enter, and delete the com.pais.handy folder. Its models folder holds the speech model, which is most of the space.

Ollama

  1. Settings → Apps → Installed apps → Ollama → Uninstall.
  2. Delete the downloaded models: press Win+R, type %USERPROFILE%, press Enter, and delete the .ollama folder. That folder holds every model you pulled, several gigabytes each for the larger ones.
